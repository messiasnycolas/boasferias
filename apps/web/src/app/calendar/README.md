# calendar

Plain dates (`DayNumber`: days since 1970-01-01, UTC, no time) and Brazilian holidays per year: national (`national-holidays`), per state (`state-holidays`, including Acre's rule that moves days to Friday), and the default list that combines them (`holidays`). Holidays are rules (fixed day or distance from Easter, with the year their law started) turned into dates by `holiday-rules`.

Glossary: [docs/business/glossary.md](../../../../../docs/business/glossary.md) (holiday). Sources: [docs/business/clt-vacation.md](../../../../../docs/business/clt-vacation.md), [docs/business/holidays.md](../../../../../docs/business/holidays.md).
