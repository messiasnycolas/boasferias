# Glossary

| Term (product, pt-BR) | Code | Meaning |
|---|---|---|
| Férias | vacation | Paid time off |
| Período | period | One continuous stretch of vacation |
| Bloco de folga | block (`offStart`..`offEnd`) | A period plus the non-work days touching it |
| Dias de folga | days off (`daysOff`) | Total days in blocks; the ranking score |
| Dias extras | extra days | Days off minus days spent |
| Dias gastos | days spent (`cost`) | CLT: calendar days of the period; PJ: workdays |
| Feriado | holiday | Default list in `calendar`; the user can remove or add days |
| Folga extra | extra day off | A day off the user adds (city holiday, company day, Carnaval) |
| Ponte / emenda | bridge | Taking workdays between days off to join them |
| Repouso semanal remunerado (DSR) | rest day | Weekly paid rest, Sunday by default |
| Período concessivo | concession period / deadline | 12 months in which the employer must grant the vacation |
| Abono pecuniário | sell a third | Selling 1/3 of the vacation for cash |
| Aviso de férias | notice | Written notice, at least 30 days before the start |
| Semana de trabalho | work week | Weekdays worked: Mon-Fri, Mon-Sat or custom |
| CLT / PJ | mode | Employee under the CLT / contractor |
